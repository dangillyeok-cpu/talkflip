"여기서 제일 ~할 사람은?" 지목 카드가 절반 넘게 들어 있어요. 다 같이 셋 세고 한 명을 찍으면 그 사람이 해명하는 식이라, 처음 보는 사이든 10년 지기든 3초 만에 텐션이 올라갑니다. 10장을 돌면 오늘의 칭호가 정해져요.

  • 3명 이상

  7. 플레이리스트 담당이 될 것 같은 사람은?
  8. 처음 보는 사람에게 먼저 말 걸 것 같은 사람은?
  9. 모두의 주문을 기억할 것 같은 사람은?
  10. 2차 가자고 제일 먼저 말할 것 같은 사람은?
  11. 처음 온 사람을 가장 편하게 해줄 것 같은 사람은?

  13. 갑작스러운 계획에도 가장 준비돼 있을 것 같은 사람은?
  14. 길 잃지 않게 제일 잘 챙길 것 같은 사람은?
  15. 제일 좋은 자리를 찾아낼 것 같은 사람은?
  16. 가장 좋은 건배사를 할 것 같은 사람은?
  17. 누군가 쉬고 싶어 할 때 제일 먼저 알아챌 것 같은 사람은?
  18. 후기를 실제보다 더 웃기게 말할 것 같은 사람은?
  19. 무인도에서 제일 오래 살아남을 것 같은 사람은?
  20. 노래방 가면 마이크 안 놓을 것 같은 사람은?
  21. 길에서 연예인 만나면 제일 먼저 말 걸 것 같은 사람은?

  24. 여기서 제일 먼저 결혼할 것 같은 사람은?
